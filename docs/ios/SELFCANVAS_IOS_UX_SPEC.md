# SelfCanvas iPhone 内测版 UI 与交互规格

## 1. 产品定位

SelfCanvas iPhone 版不是桌面无限画布的缩小版，而是一个面向移动创作的控制台：用户用自然语言发起任务，在项目中组织素材与镜头，在任务中心查看长任务，最后预览、下载和继续编辑结果。

首版目标：

- 使用账号密码登录内部环境。
- 支持生成图片、视频、音频与 AI 导演式多步骤创作。
- 能查看和编辑已有项目、节点、素材与任务。
- App 进入后台后任务继续运行，完成后通过系统通知返回结果。
- 复用现有媒体、任务和画布领域接口；不把桌面坐标、连线和大面板直接搬到手机。

## 2. 信息架构

登录后使用四个底部页签：

1. `创作`：自然语言入口、快速生成、最近项目。
2. `项目`：画布列表、镜头流和节点编辑。
3. `任务`：排队、执行、成功、失败与重试。
4. `资产`：图片、视频、音频的搜索、筛选和复用。

账号入口放在各主页面右上角头像内，避免第五个低频页签占用空间。

## 3. 视觉系统

### 3.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| Canvas | `#06070A` | 页面背景 |
| Surface | `#12141C` | 卡片、输入框、浮层 |
| Surface Raised | `#1A1D28` | 选中卡片、底部面板 |
| Primary | `#8173FF` | 主按钮、选中态、进度 |
| Primary Blue | `#4F7BFF` | 辅助强调、链接 |
| Text | `#F6F7FB` | 主要文字 |
| Muted | `#989DAC` | 辅助信息 |
| Success | `#70E1C8` | 成功、在线 |
| Warning | `#F3BF6A` | 排队、警告 |
| Danger | `#FF6B74` | 失败、删除 |

### 3.2 组件规则

- 字体使用系统 SF Pro / PingFang SC；正文不得小于 15 pt。
- 主卡片圆角 24 pt，输入框和控制项 16–20 pt，胶囊按钮使用全圆角。
- 可点击区域不小于 44 × 44 pt。
- 页面左右安全边距 16 pt，卡片内容边距 16–20 pt，组件间距采用 8 pt 网格。
- 主操作固定在拇指可达区域；危险操作不与生成按钮并排。
- 所有横向胶囊超过一屏时采用可滚动轮播，不压缩文字或截断为不可辨识的符号。

## 4. 核心页面

### 4.1 登录

内容：品牌标识、账号、密码、登录按钮；“连接设置”折叠项包含服务器地址和环境标记。

交互：

- 点击登录后按钮进入不可重复提交的 loading 状态。
- 输入错误在对应字段下方显示，不使用只出现一瞬的 Toast。
- 登录成功后保存 refresh token 到 Keychain；access token 只存内存。
- 首次成功登录后可在账号设置启用 Face ID，不在首次表单强迫授权。
- 无法连接服务器时提供“重新连接”和“检查连接设置”。

### 4.2 创作首页

页面从上至下：头像与环境状态、欢迎语、最近项目横向列表、AI 创作输入卡、模板/历史建议。

AI 创作输入卡：

- 输入区支持多行文字、粘贴、语音输入和附件。
- 模式胶囊：`AI 导演`、`图片`、`视频`、`音频`。
- 已选素材显示为可滑动缩略图列，支持拖动排序和移除。
- 发送前只显示必要参数；高级参数在创建页中配置。

提交逻辑：

- 简单模式直接创建草稿并进入生成编辑页。
- AI 导演先返回可确认的步骤方案，例如“生成分镜 → 生成关键帧 → 生成视频”，用户确认后创建任务。
- 所有提交生成唯一 `requestId`，弱网重试不得重复计费。

### 4.3 生成编辑页

采用“结果在上、内容与设置在下”的单列结构：

1. 大型预览区：空态、上传态、生成进度、结果和失败态共用同一区域。
2. 参考素材轮播：显示所有已选图片/视频/音频，可排序。
3. 提示词编辑器：默认 4–6 行，可拖动底部手柄扩大；支持标准选择、复制、粘贴、剪切和全选。
4. 固定控制条：模型、规格、模式、声音开关、生成按钮。
5. 高级设置底部 Sheet：比例、分辨率、时长、数量、种子、音频策略等。

约束：

- 图片、视频和音频素材都从统一素材选择器加入，不依赖在组合节点中二次查找。
- `@` 引用插入光标当前所在位置，同一素材允许在提示词不同位置重复引用。
- 播放、音量、下载等媒体原生控件必须与视觉位置一致，不在缩放画布中使用 CSS transform 改变命中区域。
- 生成成功后主按钮变为“继续修改”，旁边提供“加入项目”。

### 4.4 项目列表

显示项目封面、名称、更新时间、节点/素材数量和运行中任务数。支持搜索、按更新时间排序、新建、重命名和归档。

项目需要服务端保存，不能依赖浏览器或设备本地存储。进入项目时携带 revision；发生并发冲突时先显示差异提示，不自动覆盖其他设备。

### 4.5 项目详情

移动端默认采用纵向镜头流，而非无限画布：

- 顶部为项目名称、同步状态和更多菜单。
- 筛选栏：`全部`、`文本`、`图片`、`视频`、`音频`。
- 节点以卡片呈现，显示类型、缩略图、摘要、输入引用、任务状态和结果。
- 点卡片进入节点详情；长按进入多选；拖动手柄调整镜头顺序。
- “关系图”作为只读全屏概览入口，支持定位节点，但不作为默认编辑方式。
- AI/Codex 执行“定位某素材/镜头”时，App 打开对应项目并滚动到节点，高亮 1.2 秒。

### 4.6 任务中心

页签：`进行中`、`已完成`、`失败`。

每个任务显示模型、项目、当前阶段、真实进度、已用时间和预计剩余时间。操作包括取消、后台继续、打开结果和失败重试。

状态机：

`draft → uploading → ready → queued → running → succeeded / failed / cancelled`

规则：

- App 退到后台或被系统关闭不影响服务端任务。
- 重新打开后从服务端恢复状态，不把本地“100%”当作成功依据。
- 任务成功但媒体未写回节点时显示“结果同步中”，服务端补写完成后再切换成功态。
- 失败卡必须显示可读原因、追踪号和“复制错误信息”。

### 4.7 资产库

顶部搜索，下方是类型筛选、来源筛选和排序；主体为自适应网格。

交互：

- 轻点预览，长按多选，拖动到项目/节点在首版用“插入到项目”动作替代复杂跨页拖拽。
- 支持按人物、场景、道具、日期、来源、项目和收藏筛选。
- 资产详情显示被哪些项目/节点引用，并提供“定位到项目”。
- 导入中的新资产立即进入索引，服务端生成缩略图和元数据；索引失败时仍保留“待整理”入口。
- 批量操作包括加入项目、收藏、下载和打标签。

### 4.8 结果页

图片使用沉浸式缩放预览；视频和音频使用原生 AVPlayer 控件。底部主操作为下载/分享，次操作为加入项目、继续编辑、延长、重新生成。

下载使用系统分享面板，并支持保存到照片、文件或其他 App。生成参数、引用素材和任务信息放在可展开的“生成信息”中。

### 4.9 账号与设置

包含当前服务器、账号、Token 状态、Face ID、缓存、下载质量、通知、日志导出和退出登录。API Key 与供应商密钥永不直接展示给普通用户。

## 5. 全局交互规则

### 5.1 导航

- 一级页面用 Tab，二级页面用 NavigationStack push。
- 参数选择、素材选择和确认操作用中高位 Sheet。
- 预览媒体可全屏呈现；关闭后回到原滚动位置。
- 深链格式建议：`selfcanvas://project/{projectId}/node/{nodeId}`。

### 5.2 反馈

- 轻量成功使用顶部状态或按钮内反馈，失败用可持续查看的卡片/Sheet。
- 生成、上传、下载必须有进度；超过 10 秒的工作进入任务中心。
- 离线修改仅允许本地草稿，不伪装成已同步；恢复网络后明确提示提交。

### 5.3 手势与键盘

- 文本编辑区优先接收选择、复制、粘贴、剪切、全选，不把横向拖动画布手势绑定到编辑器上。
- 键盘出现时固定控制条随安全区上移；预览可收起以保证输入区至少显示 4 行。
- 媒体轮播横滑与页面返回手势冲突时，轮播距离屏幕边缘至少 20 pt。
- 删除、取消任务和退出登录需要二次确认；普通移除引用支持撤销。

## 6. 后端复用与移动端补充

可复用：登录后的用户权限、画布领域接口、媒体产物、生成任务、资产索引、SSE 状态流和下载接口。

移动端新增或明确：

- `POST /api/auth/login`、`POST /api/auth/refresh`、`POST /api/auth/logout`。
- 用户级项目列表与权限；项目和节点的 revision/CAS 写入。
- 轻量项目摘要接口，避免手机首次加载完整无限画布 JSON。
- 资产搜索、分页、标签和引用反查。
- APNs 设备 Token 注册与任务完成通知。
- 媒体缩略图/代理文件接口；预览使用代理，下载和最终渲染使用原文件。
- 任务结果由服务端写回节点，客户端只负责展示和主动刷新。

## 7. 首版范围

必须完成：登录、四个主页签、图片/视频/音频生成、参考素材、任务恢复、项目纵向镜头流、资产搜索与插入、结果下载分享、深链定位。

后续版本：多人协作、完整移动画布编辑、多轨剪辑时间线、网页内嵌 Codex 聊天、发布到第三方平台。

## 8. 验收清单

- iPhone 15/16 常见尺寸和大字体模式下无控件遮挡。
- 所有点击目标位置与视觉位置一致，播放、音量和下载命中区域不少于 44 pt。
- 提示词可连续选择多个字并执行复制、粘贴、剪切、全选。
- App 在上传或生成时进入后台，重新打开能恢复同一任务和进度。
- A 设备创建的项目能在 B 设备看到；并发修改不会静默覆盖。
- 新导入资产 5 秒内可搜索，找不到时可从“待整理”定位。
- 任务显示成功时对应结果已经可打开；未落盘不得显示成功。
- Token 过期时自动刷新一次，刷新失败才回到登录页。
- VoiceOver 有可读标签，颜色不作为唯一状态标识。
