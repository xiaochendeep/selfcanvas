# SelfCanvas UI 与交互复盘

日期：2026-07-21

## 范围

本次聚焦桌面端主路径：进入画布、添加节点、打开快捷助手、输入生成要求、进入设置。审查依据为本轮实际运行在 `http://127.0.0.1:5190/` 的页面截图与交互验证。

## 总体判断

工作台的暗色画布、节点卡片和浮层体系已经形成统一方向，主要问题不是视觉风格，而是入口密度和动作后果不够清楚。最需要优先解决的是快捷助手：服务配置占据主路径，而且空输入也能触发生成，存在误提交和无效任务风险。

## 步骤与健康度

1. 画布总览 — 基本健康。节点、组合、缩放和工具栏均可识别，但连线密度高时仍容易产生视觉噪声。
2. 添加节点 — 已改善。由超大单列改为带说明的双列卡片，常见窗口高度内可以一次看全入口。
3. 快捷助手空状态 — 已改善。服务配置收进二级入口，空输入时生成按钮禁用，并明确说明任务会进入当前画布队列。
4. 快捷助手输入就绪 — 健康。输入有效提示词后文本、图像、视频动作才启用；素材动作仍要求先附图。
5. 设置 — 基本健康。保留原有左侧分类布局；补充选中状态语义、Escape 关闭和更自然的自动保存提示。

## 本轮修正

- 防止助手欢迎语被误当成生成提示词。
- 没有明确输入时，不允许直接创建并运行文本、图像或视频任务。
- 没有附件时，不允许创建空素材节点。
- 快捷助手遵循全局 Enter 发送/换行偏好。
- 提交任务后保留状态反馈，并提供“查看画布”出口。
- 新增节点入口改为双列、带用途说明的卡片。
- 设置分段按钮增加 `aria-pressed`，分类增加当前页状态，支持 Escape 关闭。
