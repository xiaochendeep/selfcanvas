# PC 画布功能与界面回归修复 · 2026-09-08

本轮在已有未提交改动上进行增量审查与修复。范围为创作助手、画布快捷键/保存反馈、媒体索引/下载、AnyCap 参数界面和素材列表；不清理旧画布、不启动付费队列、不部署远端。

## 已确认并修复

| 问题 | 修复方式 |
| --- | --- |
| 素材按同名/大小或不同域名的相同路径误匹配，可能下载/定位到另一份文件 | 只按受控产物 ID 或完整来源 URL 关联；不再使用文件名猜测身份 |
| `//外域` 与反斜线 URL 被误判为本地下载 | 解析协议、来源和凭据后检查；拒绝外域、可执行协议与 HTML data URL |
| 保存请求未完成或存在冲突，快捷键却立即提示保存成功 | 等待 flush；只有实际 `synced` 才显示服务器已保存，失败不泄露原始错误 |
| 在弹窗、媒体控件、选中文字或中文输入法组合期间，画布快捷键仍可触发删除/缩放 | 加入编辑目标、弹层、文本选择、IME 和已处理事件隔离；禁用 React Flow 自带的 Backspace 删除路径，统一走受保护处理器 |
| 分镜全屏未管理焦点，复制/滚轮/按键可穿透到画布 | 焦点进入/恢复、Tab 循环、Esc 关闭、保持原生剪贴板并隔离事件 |
| 视频加载/播放失败没有反馈，加载前拖动进度可能抛异常 | 增加可读错误状态；有效时长出现前禁用拖动 |
| 音频节点缺少与图片/视频一致的下载入口 | 复用受控下载按钮 |
| 创作助手原请求重试使用当前模式的能力/确认状态 | 原请求类型与单独确认绑定，不复用已修改的表单 |
| 快速双击可在 React 更新前提交两次 | 同步操作锁保护生成、导入、批量生图 |
| 数字输入逐键强制最小值，不能先清空重输 | 允许中间空值；提交时再校验范围 |
| 改编方向输入自动过滤空行，吞掉回车 | 编辑时保留换行，导入文本时正常呈现 |
| 未导入草稿意外关闭、旧草稿与新标签页混淆 | 关闭提醒、草稿类型/目标画布提示、目标缺失时禁止导入 |
| 畸形网关响应使界面崩溃 | 前后端分别检查响应结构并返回可读错误 |
| AnyCap 明确不可用的模型分组仍显示可选，刷新竞态清掉新缓存 | 遵循 capability available 状态；旧请求只清理自己拥有的缓存 |
| 旧节点使用已下架模型时仍可继续提交 | 保留旧配置供查看，但明确警告并禁用按钮/快捷键提交，不静默换模型 |
| 旧音乐毫秒时长覆盖新界面秒数 | 迁移旧字段并删除过期值，以当前界面值为准 |
| AnyCap 图片接口只生成单张，但数量按钮可选多张 | AnyCap 数量固定 1；保留其他支持批量的提供方数量操作 |
| 音频设置中的下拉框被父滚动容器裁剪 | 弹窗内部下拉在文档流内展开，并支持键盘导航 |
| 豆包跨模式残留参数、只有时长的模型没有设置入口、本地合并分辨率不完整 | 按当前模式 schema 清理；时长独立触发设置入口；本地合并显示后端支持的 720p/1080p/4K |
| 不合法或过大的创作请求误报 500 | 严格 JSON/512 KiB 限额，分别返回明确 400/413/415 等错误 |
| 视频分析错误套用剧本生成的固定镜数和目标时长 | 按分析任务单独组装规则 |
| 损坏的幂等记录可能被当成未调用过的新请求 | 单条记录异常也停止调用，不自动重复计费 |
| 慢速响应反复重置读取超时；MCP 先于服务器正常超时 | 按剩余时间读取；MCP 创作调用等待上限调整为 190 秒 |

## 视觉与可访问性修整

- 创作助手：短窗口高度、长标题/镜头文字换行、辅助说明对比度、键盘焦点和细滚动条。
- 素材库：短窗口容纳过滤控件；读取失败与真正空列表使用不同状态。
- 分镜全屏：长标题截断与 tooltip，关闭按钮保持可见，文本框明确允许选择。
- 左工具栏：短窗口允许纵向滚动，按钮不再被挤到无法点击的高度；增加键盘焦点。
- 媒体播放：错误提示不挡鼠标控制；音频下载入口与播放器分离。
